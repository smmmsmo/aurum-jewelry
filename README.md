# AURUM — Genderless Fine Jewelry

A high-end editorial e-commerce frontend showcasing hand-poured recycled 18k gold and 925 sterling silver genderless jewelry.

## Tech Stack
- **React 19**
- **Vite 7**
- **Tailwind CSS v4**
- **Framer Motion**
- **Lucide React**

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## Deployment

### Vercel
Import the repository into [Vercel](https://vercel.com). Vercel detects Vite automatically (Build command: `npm run build`, Output directory: `dist`).

### Netlify
Connect this repository to [Netlify](https://netlify.com) or run `npx netlify deploy --prod`.

### GitHub Pages
An automated GitHub Actions workflow is provided in `.github/workflows/deploy.yml`. Go to **Settings → Pages → Source: GitHub Actions**.
